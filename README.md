# Daladala-Finder
web-based system that helps commuters in Dar es Salaam find daladala routes, stops, transfers, and fares between any two locations.

The Django project is in [`daladala_finder/`](daladala_finder/). See
[`daladala_finder/README.md`](daladala_finder/README.md) for how to run it, the languages
(English / Kiswahili), the database and deploying to Render (`render.yaml`).
